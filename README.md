# Kaikei - 会計ソフト

freee等を参考にした、複式簿記ベースの会計ソフトです。個人事業主・法人の両方に対応しています。

## 構成

- `server/` — Node.js + Express + Prisma (SQLite) の API サーバー
- `client/` — React + Vite + Tailwind CSS のフロントエンド

## 主な機能

- 初回セットアップウィザード(事業形態→基本情報→消費税区分→確認の4ステップ)
- 事業者管理(個人事業主 / 法人、複数事業者切り替え)
- 勘定科目マスタ(freee準拠の標準科目を自動セットアップ、追加・無効化可能)
- 仕訳入力(複式簿記、貸借バランスの自動検証)
- 取引先マスタ
- ダッシュボード(現預金推移グラフ・費用内訳グラフ)
- 総勘定元帳・合計残高試算表
- 損益計算書・貸借対照表(当期純利益を自動的に純資産の部へ反映)
- 請求書作成(インボイス制度対応の税率区分別端数処理)・仕訳への計上・印刷/PDF出力
- 銀行/カード明細CSV取込(キーワードによる勘定科目の自動提案、仕訳への変換)
- 各種帳票のCSVエクスポート(仕訳帳・総勘定元帳・試算表・損益計算書・貸借対照表)
- トースト通知・確認ダイアログによる一貫したUI体験
- 固定資産台帳(定額法・定率法の減価償却費を自動計算し、期末に仕訳計上)
- 仕訳テンプレート(よく使う仕訳をワンクリックで呼び出し)
- 家事按分(個人事業主向け。経費を事業按分率で分割し、自動的に事業主貸へ振替)
- 青色申告決算書(参考フォーマット、印刷/PDF出力対応)
- 請求書の入金消込(入金口座を選択すると売掛金を自動的に消し込み)
- 仕訳の複製(既存仕訳をコピーして新規作成)
- 取引先別残高一覧(売掛金・買掛金を取引先ごとに集計)
- 月次推移表(直近12か月の売上・費用・純利益をグラフ表示)

## セットアップ

```bash
npm install
```

`server/.env` に `DATABASE_URL` が設定済みです(SQLiteファイル)。初回のみ以下でDBを作成しサンプルデータを投入します。

```bash
cd server
npx prisma migrate deploy
npx tsx prisma/seed.ts
```

## 起動

```bash
npm run dev:server   # http://localhost:4000
npm run dev:client   # http://localhost:5173
```

ブラウザで `http://localhost:5173` を開いてください。
