# Kaikei - 会計ソフト

freee等を参考にした、複式簿記ベースの会計SaaSです。個人事業主・法人の両方に対応し、
メール認証・Stripeによる月額課金・マルチテナント分離を備えています。
Cloudflareの無料枠(Workers + D1)だけでホスティングできる構成です。

## 構成

- `server/` — API(Hono + Prisma + D1)
- `client/` — React + Vite + Tailwind CSS のフロントエンド

本番では静的サイト(`client/dist`)とAPIを**1つのCloudflare Worker**からまとめて配信します
(ルートの `wrangler.toml` の `[assets]` 設定)。同一オリジンなのでCookieのcross-site対応は不要です。
ローカル開発では Vite Dev Server (`:5173`) が `wrangler dev` (`:4000`) にAPIリクエストを
プロキシします(詳細は [DEPLOYMENT.md](DEPLOYMENT.md))。

## 主な機能

### 会計機能
- 初回セットアップウィザード(事業形態→基本情報→消費税区分→確認の4ステップ)
- 事業者管理(個人事業主 / 法人、複数事業者切り替え)
- 勘定科目マスタ(freee準拠の標準科目を自動セットアップ、追加・無効化可能)
- 仕訳入力(複式簿記、貸借バランスの自動検証)・複製・テンプレート・CSV一括インポート・一括削除・絞り込み(科目/区分/金額)
- 家事按分(個人事業主向け。経費を事業按分率で分割し、自動的に事業主貸へ振替)
- 取引先マスタ・取引先別残高一覧(売掛金・買掛金)
- ダッシュボード(現預金推移・費用内訳・やること一覧(未入金/下書き)・今月の売上の前月比/前年同月比)
- 経営分析(収益性・安全性・効率性の各指標を前年同期と比較。会計データの「読み方」を提供)
- 総勘定元帳・合計残高試算表・損益計算書・貸借対照表
- 請求書作成(インボイス制度対応)・仕訳への計上・入金消込・印刷/PDF出力・メール送信
- 銀行/カード明細CSV取込(勘定科目の自動提案)
- 固定資産台帳(定額法・定率法の減価償却費を自動計算し、期末に仕訳計上)
- 青色申告決算書(参考フォーマット、印刷/PDF出力対応)
- 法人税申告書(概算・参考フォーマット。法人のみ、印刷/PDF出力対応)
- 損益分岐点分析(限界利益率・安全余裕率)
- 決算処理(期末チェックリスト・固定資産の減価償却費の一括計上)
- 各種帳票のCSVエクスポート
- グローバル検索(Ctrl+K / ⌘K):ページ・操作・仕訳・取引先・請求書を横断検索
- サイドバーの機能カテゴリ分け(取引入力 / レポート / 設定)

### アカウント・課金・セキュリティ
- メールアドレス+パスワードによるサインアップ/ログイン(JWTセッションCookie)
- 二要素認証(TOTP。認証アプリでQR登録、ログイン時にワンタイムコード要求、バックアップコード対応)
- パスワード再設定(メールによる本人の自己復旧 / 管理者による一時パスワード発行)
- 監査ログ・ログイン履歴(ログイン成功失敗・権限変更・2FA有効無効などを記録、管理画面で閲覧)
- 管理者によるアカウント復旧(一時パスワード発行 / 2FA解除)
- 事業者データはログインユーザーごとに分離(他ユーザーのデータには一切アクセス不可)
- Stripeによる月額サブスクリプション(14日間無料トライアル、Billing Portal連携)
- 未ログイン時に表示するランディングページ

## セットアップ(ローカル開発)

```bash
npm install
cp .dev.vars.example .dev.vars   # JWT_SECRETを生成して設定
npm run d1:migrations:apply:local  # ローカルD1にスキーマ反映
npm run build:client               # client/dist を用意(wranglerのassets配信に必要)
```

## 起動

```bash
npm run dev:server   # http://localhost:4000 (wrangler dev / Workers)
npm run dev:client   # http://localhost:5173 (Vite)
```

別ターミナルで初回データ投入(`dev:server` 起動中に実行):

```bash
cd server
npm run prisma:seed
# 出力される wrangler d1 execute コマンドを実行するとサブスクリプションがACTIVEになります
```

ブラウザで `http://localhost:5173` を開いてください(デモログイン: `demo@example.com` / `password123`)。
Stripeの `STRIPE_SECRET_KEY` 等を設定しない場合、会計機能はそのまま使えますが
決済(課金)機能は「準備中」として無効化されます。

## デプロイ

[DEPLOYMENT.md](DEPLOYMENT.md) にCloudflare Workers + D1 へのデプロイ手順と
Stripeの設定手順をまとめています。

※ メール送信機能(請求書送信・パスワード再設定)は `RESEND_API_KEY` と `MAIL_FROM` を
設定すると有効になります(未設定時は「準備中」として無効化)。
